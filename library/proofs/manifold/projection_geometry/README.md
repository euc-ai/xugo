# projection_geometry — smooth total spaces and local unitary frames

A frame is an actual rectangular matrix of smooth orthonormal columns spanning im P on an open set. Bundle charts use the base chart followed by real and imaginary fibre coordinates in interleaved order. Their smooth structure is independent of the chosen frames. Constant rank r fixes the total dimension; varying-rank statements apply separately to components.
