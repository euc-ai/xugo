# index_comparison — the normal Bott model and equality of the two indices

Compactly supported tangent classes are realized on the closed torus through the half-period Euclidean chart. A metric transports the analytic cotangent index to tangent classes; its independence is a theorem. Open embeddings use the differential, its inverse on the open tangent image, and compact-support extension.

The normal Bott operator supplies embedding compatibility. Its full orthogonal covariance descends through normal frames; the graded product is glued after order reduction, and its Gaussian spectral gap controls localization. The resulting symbol is the Thom pushforward with the fixed z convention. Point normalization uses the same model. The final equality then compares both pushforwards in one Euclidean compact-support group.
