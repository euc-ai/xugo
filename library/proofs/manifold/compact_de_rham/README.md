# compact_de_rham — compact-support forms and cohomology

Compact support is imposed on whole normalized forms before taking cohomology. Coboundaries have compactly supported primitives. Proper smooth maps pull back classes; open inclusions extend by zero. The product takes one compactly supported factor and one ordinary factor. Integration uses an oriented atlas and only the top degree.
