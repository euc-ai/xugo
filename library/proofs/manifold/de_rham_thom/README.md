# de_rham_thom — fibre-compact Thom forms and geometric pushforward

The Thom form is a closed fibre-proper form whose actual fibre integral is one. It is not chosen by an inverse identity on cohomology. Wedging it with a pulled-back compact form defines the cohomological Thom map. Fibre integration supplies its inverse as a theorem; the construction uses local compact radial forms and the relative de Rham gluing argument. Base vectors precede the complex-oriented fibre vectors.
