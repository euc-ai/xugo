# compact_chern — relative connections and the compact Chern character

A smooth relative triple carries connections which intertwine through its bundle map outside one compact set. The difference of their Chern forms is therefore compactly supported. The chosen cohomology class is characterized by these geometric witnesses, and its independence is proved separately. Continuous triples and their defining relations must first be replaced by smooth data with controlled compact support.

The compact character is componentwise, landing in the actual compact de Rham quotient. It is not defined through an index or a numerical integral.
