# analytic_index — the Fredholm index descended to compactly supported cotangent classes

The symbol class is represented by a continuous map between the two pulled-back projection bundles which agrees with the homogeneous symbol outside a compact neighborhood of the zero section. Changing that extension changes the triple by a compactly supported straight-line homotopy.

The analytic index is the integer obtained from any zero-order elliptic realization of the class. Existence of representatives and independence under every relative-triple relation are theorems, not properties built into an abstract index theory. Elliptic regularity compares all integer Sobolev orders, and order reduction relates a general-order operator to the zero-order construction.
