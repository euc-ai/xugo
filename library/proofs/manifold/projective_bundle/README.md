# projective_bundle — projection lines and injective cohomological pullback

The fibre consists of rank-one Hermitian projections Q with P Q=Q. In a local unitary frame, each positive diagonal entry selects an affine projective chart; ratios of matrix entries give its complex coordinates. The tautological projection Q and its orthogonal complement P-Q split the pulled-back bundle.

The cohomological splitting principle uses proper pullback along these actual compact-fibre bundles. Fibre integration of the (r-1)st power of the dual tautological first Chern class is one, giving a left inverse to pullback. No Euler class is cancelled.
