# torus_manifold — the closed smooth torus and its half-period Euclidean chart

The n-torus is the product of n unit circles, normalized to zero after coordinate n. Rotated stereographic charts give its smooth atlas. The half-period exponential chart embeds an open cube, and a coordinatewise bounded diffeomorphism first carries all of Euclidean space into that cube.

This closed ambient manifold supplies the analytic index for compactly supported Euclidean symbols. Its construction is geometric; the Fourier sequence model is connected through the same 2π angular coordinates.
