# sigma_algebra — sigma algebras on explicit carriers

A sigma algebra is a family of subsets of a fixed carrier, closed under relative complements and countable unions. Generated sigma algebras and the pi–lambda theorem describe how a collection of tests determines measurability. The join of a family of σ-algebras over an index set is the one their union generates.
