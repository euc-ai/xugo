# l2_martingale — square-integrable martingales and L2 convergence

The conditional-expectation relation meets Hilbert projection in square-integrable martingales. Orthogonal increments give the energy identity and turn L2 boundedness into a Cauchy condition; completeness produces a limit measurable for the sigma algebra generated by the filtration. The conclusions here concern L2 convergence, with no almost sure convergence assertion.
