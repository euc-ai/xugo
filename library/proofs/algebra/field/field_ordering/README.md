# field_ordering — sums of squares, proper preorderings and order extension

A preordering contains every square and is closed under addition and multiplication inside a field carrier. Proper means that it excludes minus one. Zorn extension gives a positive cone, hence an order; a nonsum of squares can be made strictly negative in a formally real field.
