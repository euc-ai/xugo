# artin — nonnegative polynomials over real closed fields are sums of rational squares

Artin uses the parameter-preserving embedding mode. A nonsum of squares in the rational function field is negative in some ordering; a real closure supplies a real closed extension and the generic tuple supplies a negative value. Elementary descent contradicts nonnegativity over the base. No infinitesimals or standard-part construction is used.

| Member | Statement |
|---|---|
| `NegativeValueDescent` | A negative value in a real closed extension descends along the specified ordered embedding. |
| `Artin` | Every everywhere-nonnegative polynomial over a real closed field is a sum of rational squares. — card |
