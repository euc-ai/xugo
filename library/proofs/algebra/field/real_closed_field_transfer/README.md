# real_closed_field_transfer — sentence transfer and elementary embeddings of real closed fields

Both transfer theorems allow different host types and proper carriers. Quantifiers are eliminated once, in A × B, which holds a copy of each field and its order along a pairing with a chosen element of the other type; transport is absent from the public conclusions. Any two real closed fields satisfy the same sentences; an elementary embedding carries every formula along a given homomorphism, at every environment.

| Member | Statement |
|---|---|
| `CommonElimination` | One quantifier-free equivalent serves the real closed fields on two types. |
| `SentenceTransfer` | Any two real closed fields satisfy the same ordered-ring sentences. |
| `EmbeddingElementary` | A homomorphism of real closed fields is elementary: a formula holds at an environment exactly when it holds at the environment carried along. |
