# algebraically_closed_field_transfer — same-characteristic sentence transfer and elementary embeddings of algebraically closed fields

Both transfer theorems allow different host types and proper carriers. Quantifiers are eliminated once, in A × B, which holds a copy of each field along a pairing with a chosen element of the other type; transport is absent from the public conclusions. Sentence transfer needs the two fields to share their characteristic; an elementary embedding carries every formula along a given homomorphism, at every environment.

| Member | Statement |
|---|---|
| `CommonElimination` | One quantifier-free equivalent serves the algebraically closed fields on two types. |
| `SentenceTransfer` | Algebraically closed fields of the same characteristic satisfy the same ring sentences. |
| `EmbeddingElementary` | A homomorphism of algebraically closed fields is elementary: a formula holds at an environment exactly when it holds at the environment carried along. |
